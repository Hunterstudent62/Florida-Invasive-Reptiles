# Florida Invasive Reptiles

A portfolio project combining GIS analysis, Power BI visualization, written research, and field observations related to invasive reptiles in Florida.

## Project Overview

This project examines invasive reptile occurrence patterns across Florida using QGIS and Power BI. It combines cleaned occurrence data, spatial analysis, exported maps, an interactive dashboard, and a written report discussing geographic patterns, data limitations, field observations, and invasive-species management.

## Repository Structure

- `report/` — written project report
- `qgis/` — QGIS project file
- `qgis/data/` — cleaned/project-ready datasets and GeoPackage
- `qgis/outputs/` — exported map PDFs
- `powerbi/` — Power BI project file
- `images/` — screenshots and figures for the portfolio and README
- `documentation/` — data-source, licensing, methodology, and project notes
