# Florida Invasive Reptiles

Portfolio project combining GIS analysis, Power BI visualization, written research, and field observations related to invasive reptiles in Florida.

## Repository Structure

- `report/` — final written report in PDF and DOCX format
- `qgis/` — QGIS project files, supporting data, and exported maps
- `qgis/data/` — cleaned and project-ready GIS datasets
- `qgis/outputs/` — exported map PDFs and other GIS outputs
- `powerbi/` — Power BI project file and related materials
- `images/` — screenshots and figures used for the portfolio and report
- `documentation/` — data-source, licensing, methodology, and project notes
